# AviUtl2（ExEdit2 2.1.16）界面分析与 Freya NLE 借鉴设计

分析日期：2026-11-05。代码基线：`055ee750`（`main`）。
二进制基线：`AviUtl2/aviutl2.exe` 2.1.16（PE32+ x86-64，Ghidra 项目
`AviUtl-reverse`，14,148 个函数 / 88,877 个符号），同目录官方发行包附带
`style.conf`、`system.conf`、`aviutl2.txt`。
目标：把 AviUtl2 的界面设计当作参照，判断哪些值得学、哪些不该照搬，并给出在
Freya NLE（Rust + Slint）里可落地、可验收的实施批次。

本文只描述**界面**。编辑模型、渲染管线和插件 ABI 不在范围内。

## 1. 结论摘要

AviUtl2 的界面不是"经典 AviUtl + 扩展编辑"的翻新，而是一次重做：单窗口内自由
分组的面板、统一的深色灰阶、以绝对时间为刻度的标尺、以及一条贯穿窗口的脚注栏。
它最值得借鉴的是**信息密度与状态可见性**，最不该照搬的是**全自绘、无原生控件、
单主题、固定像素**。

因此本方案不重写窗口系统，而是在现有原生窗口 + 标准控件的基础上，吸收四件事：

1. 一套显式的界面度量与色彩令牌（对应 `style.conf` 的 `[Layout]`/`[Color]`）。
2. 面板标题栏 + 右侧动作图标的固定结构。
3. 时间标尺补上绝对时间，窗口底部补一条脚注栏。
4. 预览下方重排为"时间 → 帧位 → 走带 → 倍速"的播放器控制条。

## 3. 界面结构

### 3.1 窗口模型

单应用窗口内放置所有面板；面板之间是可拖动的分隔条，拖动边界可改尺寸或换位，
这由 `Window::WindowFloating`、`Window::WindowFooter`、`Window::WindowMenuManager`
一类实现承担。每个面板带自己的标题头，右键菜单提供三类操作：

- `ウィンドウ配置`（`0x49712a`）：把面板放入哪个显示区组；
- `ウィンドウのグループを作成 / に追加 / から外す`（`0x497022` / `0x497062` /
  `0x497042`）：同区面板合并为标签页；
- `ウィンドウを分離 / 統合 / 閉じる`（`0x497092` / `0x4970ea` / `0x497102`）：
  拆成独立操作系统窗口或并回主窗口。

另有 `レイアウト名` / `レイアウトを作成` / `同名のレイアウトが存在しています` /
`メインウィンドウの位置も保存する`（`0x49a01a` 起），说明布局按名称保存，并可
选择是否连主窗口位置一起存。

### 3.2 面板清单

RTTI 中的 `Component::*` 类名与 `.rdata` 标题一一对应，构成完整的界面单元表：

| `MarkListComponent` | マークリスト `0x45fc4a` | 标记帧清单 | 无 |
| `LayerSettingComponent` | レイヤー設定 `0x45bb32` | 选中图层的坐标/音量设置 | 无 |

`バッチ出力`、`終了`、`プロジェクトを保存して終了`（`0x486d0a`–`0x486cca`）。

## 5. 视觉语言

`style.conf` 的 `[Color]` 以十六进制给出整套调色，可直接归纳为四层加一组语义色：

| 层 | 取值 |
| --- | --- |
| 画布/背景 | `Background=202020`，`WindowSeparator=000000` |
| 面板 | `TitleHeader=404040`，`WindowBorder=585858`，`Grouping=383838`（hover `404040`、选中 `484848`） |
| 控件 | `ButtonBody=606060`（hover `808080`、按下 `a0a0a0`、禁用 `484848`、选中 `7070c0`），`LabelBody=a86060` |
| 文本 | `Text=ffffff`，`TextDisable=909090`，`TextSelect=6060e0` |
| 脚注栏 | `Footer=304080`，进度 `903838`→`b84848` |
| 图层 | 行 `Layer=404040`、名区 `LayerHeader=4a4a4a`、hover `585858`、隐藏 `343434`、选中 `3c4054` |
| 对象类型 | 视频 `3040e0`、音频 `d04030`、控制 `30b0c0`、视频滤镜 `30b030`、音频滤镜 `b8b030`；各带选中亮版 |
| 时间相关 | 帧光标 `c83030e0`（宽版 `c8303080`）、播放光标 `e0e080e0`、标记帧 `68c868`、BPM 起点 `c8c840` |
| 预览辅助 | 网格 `808080c0`、锚点 `c0c0c0`、中心点/句柄分 X/Y/Z 三色（`f05050`/`208020`/`5050f0`） |
| 电平表 | 红 `c82020`、黄 `c0a800`、绿 `00a000`，均带暗底 |

值得注意的是：对象、图层、时间语义各自成组，且**同一元素都有 hover / 选中 /
禁用三态**。这套令牌是 AviUtl2 视觉一致性的来源，也是它最难在自绘体系外复刻的
部分——Freya 需要把它映射到 Slint 的调色板与自定义面板表面两套通道上。

## 6. 关键交互与信息呈现

### 6.1 绝对时间标尺

截图中的标尺读数是 `00:00:00.00 / 00:00:03.33 / 00:00:06.66 / 00:00:10.00`
——`HH:MM:SS.cc`（百分秒），不是帧号。对象条按类型着色，选中对象加虚线外框；
帧光标是一条红色竖线，播放光标是另一条浅色竖线。`[Format]` 里的
`{CurrentTime} / {TotalTime} | {CurrentFrame} / {TotalFrame}` 说明时间与帧号是
**并列**呈现的，而不是互相替代。

### 6.2 脚注栏

`[Format]` 定义了两条模板：

- `FooterLeft={CurrentTime} / {TotalTime}  |  {CurrentFrame} / {TotalFrame}`
- `FooterRight={SceneName}  |  {Resolution}  |  {FrameRate}  |  {SamplingRate}`

模板变量还包括 `{ProjectName}`、`{AppVersion}`。脚注栏同时承载进度色
（`FooterProgress`），即长时间任务（输出、扫描）的状态显示位置固定在窗口底部，
不弹模态框。

### 6.3 播放器控制条

预览下方 40px 控制条：左侧时间读数（16px 字号），一条带帧刻度的手动拖拽条，
中部走带按钮组（播放/停止/暂停/上一帧/下一帧），右侧音量与帮助。标尺与控制条
共享同一条时间语义，滚动/缩放不改变两处读数的一致性。

### 6.4 对象设置的行结构

设置项是固定的两列：左列 96px 标签（含单位与图标），右列数值。数值上方叠加
细轨道条表示范围与当前值；`SettingItemHeight=22`、`SettingItemMarginWidth=6`
让一屏能放下 20 行以上。设置区头部高 48px，显示对象类型与开关。

### 6.5 密度可选

`LayerHeightMenu0=小,24 / 中,32 / 大,48`（最多 10 档）说明图层行高是用户可切换
的密度档位，而不是写死值。这是"专业软件允许用户决定信息密度"的直接证据。

## 7. 与 Freya NLE 现状对照

| 维度 | AviUtl2 | Freya NLE 现状（`055ee750`） | 判断 |
| --- | --- | --- | --- |
| 窗口 | 单窗口内分组/分离/标签 | 多操作系统窗口 + 项目标签，原生菜单 | 保留现状；只在时间线侧栏引入标签式分组 |
| 外观 | 深色单主题，自绘 | `Palette` + 跟随系统明暗，标准控件 | 保留明暗双主题；补一套界面令牌 |
| 标尺 | 绝对时间（百分秒） | 纯帧号（`timeline.slint` 标尺） | 补时间读数，帧号保留为主 |
| 底部状态 | 24px 彩色脚注栏 + 进度 | 主窗口有 24px 状态栏；时间线没有 | 时间线补脚注栏 |
| 预览控制 | 40px 控制条：时间→刻度→走带→音量 | 38px 工具条：滑条→帧计数→走带→电平→倍速 | 重排为 AviUtl2 的信息顺序 |
| 对象颜色 | 按类型成组、带三态 | 仅音频/部分图形显式着色，其余走主题蓝 | 补齐类型色令牌 |
| 图层名区 | 96px，名称 + 状态 | 60px，圆点 + 序号 + L | 加宽到 96px，显示 `Layer N` |
| 面板标题 | 20px 标题头 + 右侧图标 | 无统一标题头 | 新增可复用标题头 |
| 设置密度 | 小/中/大 可选 | 固定 30px 行高 | 先出令牌，设置入口后置 |

## 8. 设计决定

### 采用

1. **显式令牌**：把 AviUtl2 的度量与色彩整理成 `AppTheme` 的 `chrome` 与
   `object-*` 令牌，明暗两套派生，替换散落的魔法数字。
2. **面板标题头**：统一为"标题 + 右侧动作"的 22px 结构，先用于时间线侧栏。
3. **时间双读数**：标尺主行帧号、次行 `HH:MM:SS.FF`；脚注栏并列时间与帧。
4. **脚注栏**：24px，左段时间/帧，右段场景名 | 分辨率 | 帧率，随播放头更新。
5. **播放器控制条**：时间读数前置，走带居中，倍速后置。
6. **类型色**：视频/音频/文本/控制/滤镜各一色，兼顾明暗对比。
7. **图层密度**：行高 32、名区 96 作为新默认，保留设置项覆盖。

### 改造后采用

- **分组标签**：只在时间线右侧栏（媒体库 / 对象信息）做标签，不做全局停靠。
- **布局保存**：沿用现有 workspace 预设，增加"保存主窗口位置"选项（后续批次）。

### 不采用

- 全自绘控件：会丢掉 Slint 的无障碍角色、键盘导航和系统主题。
- 单主题/固定字号：与现有明暗跟随和 DPI 策略冲突。
- 右键拖拽、Alt+点击等隐藏手势：不可发现，且与现有关联菜单冲突。
- 单文档单窗口：Freya 的多项目标签是更好的模型。
- 固定日文字体栈：Freya 需要 i18n 与系统字体回退。

## 10. 验收与风险

验收以可观察行为为准：标尺同时给出帧号与时间；脚注栏随播放头、场景切换更新；
明暗两套主题下文字与背景对比度不低于现状；窗口缩到最小宽度时脚注栏不截断关键
读数；播放器控制条在 640px 宽窗口内不溢出。

风险与对策：

- **Slint 无文本格式化**：时间码用整型运算 + 补零函数在 `.slint` 内实现，避免
  每帧回传宿主。
- **脚注栏数据依赖**：场景名/分辨率/帧率由投影层随播放头同步下发，缺省值为空
  字符串，避免出现"0x0"这类假数据。
- **度量改动影响既有截图验收**：新默认值只对新建配置生效，旧配置保留用户值。

| `timeline.slint` | 标尺主行帧号、次行时间码（按刻度宽度决定每 1/2/4/8 个刻度标一次）；底部脚注栏；媒体库改为标题头 + 面板；默认行高 32、名区 96；播放头改为帧光标红。 |
| `timeline-items.slint` | 图层名区改为"可见性圆点 + `Layer N` + 锁定标记"，隐藏态整体降亮。 |
| `projection.rs` / `settings.rs` | 投影场景名/分辨率/帧率与整数播放头；新建配置的默认行高与名区宽度取 32 / 96。 |

验证方式：`cargo test -p freya-nle`（53 项通过，含新增的帧率取整与分辨率文本两项），
以及 `tools/ui-snapshot`（新增的离屏渲染工具，用 Slint 软件渲染器把同一份
`ui/app.slint` 画成 PNG）。用它分别渲染了时间线与预览窗口的深色、浅色版本，确认：
脚注栏落在窗口底部且不遮住内容；标尺在 1.6 px/帧下仍显示时间码；图层名区 96px
时两位数的 `Layer 10` 不被截断；隐藏层与锁定层的状态不只靠颜色区分。

`tools/ui-snapshot` 只用于设计核对，不参与发布构建；它固定与编辑器相同的 Slint
版本，避免软件渲染器与编译器版本错位。

## 12. B2 实施记录

对象设置窗口是第二个高频面。AviUtl2 的该窗口由 48px 区头（对象类型 + 动作）、96px
标签列和 22px 行组成。本批按同一结构改造，但**没有**把行高压到 22px：AviUtl2 自绘
20px 控件，而 Slint 标准 LineEdit/ComboBox/Button 需要 26px 才不至于误触且保持可读；
压到 22px 会让输入框与下拉框互相挤压。因此行高取 30px，并把 22px 记为后续"紧凑"
密度档位（B3）的取值。

| 位置 | 改动 |
| --- | --- |
| `theme.slint` | 新增 `setting-header-height: 48px`；`setting-row-height` 由 22px 调整为 30px，并注明 22px 属于紧凑档。 |
| `object-settings.slint` | 顶部 38px 工具条换成 48px 区头：左侧效果列表开关，中间"对象名 + 对象设置/音频对象"两行，右侧多选提示；侧栏与内容区从 48px 开始。内容区不再重复页面标题。 |
| `object-controls.slint` | 行高与标签列改用令牌：数值/整数 30px、效果头 34px、分区头 24px、文本 62px；choice/text/path/font/color/unsupported 与布尔行的标签统一 96px 列；布尔行按"标签左、复选框右"排列，点击区域仍覆盖整行剩余宽度。 |

验证：`cargo test -p freya-nle` 通过；离屏渲染 900×650 与 680×600 两种尺寸，
后者（窗口最小宽度）下数值行、滑块与标签均完整可见，无横向截断。

## 13. B3 实施记录

AviUtl2 的 `LayerHeightMenu` 允许把图层行高在小/中/大之间切换（`style.conf`
[Layout] 的 24/32/48）。本批在"时间线 → 外观与尺寸"里加了同名档位，并保留原有的
"Track height" 数值项：档位只是给同一个值起名，手改数值后档位显示为"自定义"。

| 位置 | 改动 |
| --- | --- |
| `system-settings.slint` | 新增"图层密度"下拉（紧凑 24 / 标准 32 / 大 48 / 自定义）；`changed timeline-track-height` 反推档位，避免下拉与实际值不同步；草稿默认值同步为 32 / 96。 |
| `projection.rs` | 补齐对象类型色：控制类对象（`camera` / `camera_control` / `scene`）用青色，音频用红色，媒体对象继续用主题的视频蓝；与 `theme.slint` 的 `object-*` 令牌一致。 |
| `tests.rs` | 新增类型色映射测试，覆盖音频、三种控制对象与媒体回退。 |

验证：`cargo test -p freya-nle`（54 项）通过；离屏渲染"时间线"与"系统设置→时间线"
两页，确认档位显示为"标准"、轨道高度 32、图层名区 96，且时间线上控制对象与音频对象
已按类型着色。

## 14. B4 实施记录

AviUtl2 把预览放在图层编辑正上方，并在预览下方放一条走带条。本批在时间线窗口里
加入同一块预览面板：图片按 `contain` 留黑边、下方是共享的走带条；面板高度由
`preview-pane-height`（默认 320px）决定，其下的分隔条可拖动，图层区占据剩余空间。独立预览窗口继续保留，两者由"显示"菜单与系统设置里的
"在时间线内显示预览"开关控制。

| 位置 | 改动 |
| --- | --- |
| `transport-bar.slint`（新增） | 从预览窗口抽出的走带条：时间 → 走带条 → 播放/前后帧，可紧凑模式隐藏电平与倍速；`speed-editing` 上报焦点，供菜单加速键让位。 |
| `main.slint` | 改用 `TransportBar`，窗口布局不变。 |
| `timeline.slint` | 新增 `preview-visible` / `preview-image` / `playing` 与 `seek` / `previous-frame` / `toggle-playback` / `next-frame` / `toggle-preview` 回调；"显示"菜单加入开关。 |
| `playback.rs` / `projection.rs` | 合成帧同时投影到时间线；播放状态同步。 |
| `callbacks.rs` | 预览面板的走带回调转发给主窗口命令；开关写入 `timelinePreviewVisible`，下次启动恢复。 |
| `system-settings.slint` / `settings.rs` | 设置窗口加"在时间线内显示预览"复选项，随 Apply 持久化。 |

边界：分隔条只响应指针拖动，键盘调整留待后续；独立预览窗口仍然存在，用户可自行
选择只用合并形态。

合并形态目前默认关闭。原因不是实现成本，而是窗口职责：独立预览窗口还持有项目标签栏
和主菜单，如果默认改为合并形态，就必须先把这两者搬进时间线窗口，否则会出现两个
预览窗口或一个没有标签栏的主窗口。这属于下一步的产品决定，已记录在 §9 的"改造后
采用"里，不在本轮范围内。

验证：`cargo test -p freya-nle` 通过；离屏渲染 1280×720 的合并形态，确认预览、走带条、
标尺、图层与脚注栏自上而下排列，图层区未被预览挤没。

## 15. B5 实施记录

AviUtl2 把长时间任务的进度放在脚注栏（`style.conf` 的 `FooterProgress`），而不是塞进
内容区。本批给 `FooterBar` 加了 `progress` 通道，并把它用在包管理器上：

| 位置 | 改动 |
| --- | --- |
| `chrome.slint` | `FooterBar.progress`（0–1，负数隐藏）沿底边绘制进度色。 |
| `package-manager.slint` | 内容区外包一层纵向布局，底部换成全宽脚注：左侧状态文字、底部进度条；移除原先内联的 `ProgressIndicator` 与 11px 状态行。 |

没有照搬的部分：导出窗口的进度仍在模态层里（需要同时给出取消与二次确认），
工程/场景设置这类小对话框沿用系统标题栏，不再叠加窗口内标题头。

验证：离屏渲染包管理器的空闲与进行中两种状态，确认脚注常驻、进度条按 42% 显示。

## 16. B6 实施记录

B4 之后合并形态仍需要一个前提：时间线窗口必须能独立承担工作区职责。AviUtl2 的
单窗口里同时有菜单、场景标签和预览；Freya 的项目标签与"重新打开预览窗口"原本只在
预览窗口里。

| 位置 | 改动 |
| --- | --- |
| `timeline.slint` / `main.slint` | 合并形态下在场景标签上方显示项目标签（复用 `ProjectTab`，多于一个项目时才出现）；两个窗口的"显示"菜单都新增"显示预览窗口"（保持菜单一致，否则切换焦点时菜单项会消失）。 |
| `projection.rs` | 项目标签模型与当前索引同时投影到两个窗口。 |
| `callbacks.rs` | 项目切换/关闭转发给预览窗口拥有的命令；"显示预览窗口"调用 `main.show()`。 |
| `lifecycle.rs` | "合并工作区"动作：开启预览面板、必要时增高窗口、持久化偏好、隐藏预览窗口；"独立窗口"动作反向执行。两个窗口的"视图 → 工作区"菜单都可触发。 |

默认值仍为"独立窗口"，但"合并工作区"现在是一键可逆的布局动作；用户也可以在关闭
预览窗口后从时间线菜单把它找回来，不会出现无法恢复的状态。

验证：`cargo test -p freya-nle` 通过；离屏渲染 1280×760，确认项目标签、场景标签、
预览、走带条、标尺、图层与脚注栏的完整顺序。

## 17. B7 实施记录

B4 的分隔条只能拖动，且高度不保留。AviUtl2 的边界可调、布局会记住，这里补齐两点：

| 位置 | 改动 |
| --- | --- |
| `timeline.slint` | 拖动结束（指针抬起/取消）时发出 `preview-height-changed`；"显示"菜单新增"加高预览 / 缩短预览"（每次 40px，限制 120–720px），同样发出该回调。 |
| `callbacks.rs` | 回调把高度写入 `timelinePreviewHeight`。 |
| `settings.rs` / `main.rs` | 启动与设置同步时读取该值（缺省 320px，限制 120–720px）。 |

菜单项同时补上了没有指针时的调整路径——这是 B4 记录里"键盘调整留待后续"的兑现。

验证：`cargo test -p freya-nle` 通过；离屏渲染确认默认 320px 与图层区比例不变。
